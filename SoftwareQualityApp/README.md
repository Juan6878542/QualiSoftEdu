# Evaluador de Calidad de Software (Proyecto educativo)

Este proyecto es una aplicación web estática (HTML/CSS/JS) que explica qué es la calidad del software y permite evaluar un aplicativo en un entorno educativo. Genera una calificación final entre 0 (mínima) y 5 (máxima) y exporta resultados en JSON.

## Estructura
- `index.html` - página principal
- `styles.css` - estilos
- `app.js` - lógica de evaluación
- `README.md` - este archivo

## Modelo de evaluación
- Categorías: Estándares de Calidad (50%), Código (30%), Programación (20%).
- Cada criterio se puntúa de 0 a 5. La calificación final se calcula como media ponderada.

## Cómo ejecutar
### Localmente
1. Descomprimir el ZIP.
