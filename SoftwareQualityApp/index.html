Evaluador de Calidad de Software

Aplicación educativa para entender normas, modelos, estándares y evaluar un aplicativo según calidad, código y programación.

¿Qué es la Calidad del Software?

La calidad del software es el grado en que un producto de software cumple con los requisitos, satisface las necesidades del usuario y se ajusta a normas, modelos y estándares de la industria. Incluye atributos como funcionalidad, fiabilidad, usabilidad, eficiencia, mantenibilidad y portabilidad.

Normas, Modelos y Estándares

  • Normas: Documentos oficiales (por ejemplo, ISO/IEC 25010, ISO/IEC 9126) que describen atributos de calidad y criterios.
  • Modelos: Marcos conceptuales como CMMI (madurez de procesos) que ayudan a mejorar prácticas de desarrollo y aseguramiento de la calidad.
  • Estándares: Guías de codificación, revisiones, pruebas y herramientas (por ejemplo, IEEE, OWASP para seguridad).

Código y Programación

Buena calidad en código implica legibilidad, modularidad, pruebas automatizadas, documentación, manejo de errores y seguimiento de buenas prácticas (naming, comentarios, patrones). El cumplimiento de estándares de codificación facilita mantenibilidad y reduce defectos.

Modelo de Evaluación (métricas cuantitativas)

El modelo calcula promedios por categoría y luego una puntuación final como media ponderada:

  • Estándares de Calidad (peso 50%)
  • Código (peso 30%)
  • Programación (peso 20%)

Cada criterio se ingresa de 0 a 5. El resultado es una puntuación numérica entre 0 y 5 y un desglose porcentual.
