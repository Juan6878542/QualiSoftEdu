Buenas prácticas de código

En esta sección se muestra un ejemplo de código limpio y mantenible que sigue las normas de calidad de software.


# Ejemplo de buenas prácticas en Python
# Cumple con los principios de claridad, mantenibilidad y documentación.

def calcular_promedio(calificaciones):
    """
    Calcula el promedio de una lista de calificaciones.
    Args:
        calificaciones (list): Lista de valores numéricos.
    Returns:
        float: Promedio calculado.
    """
    if not calificaciones:
        return 0
    return sum(calificaciones) / len(calificaciones)

# Uso de la función
valores = [4.5, 3.8, 5.0, 4.2]
promedio = calcular_promedio(valores)
print(f"Promedio: {promedio:.2f}")

✅ Este ejemplo aplica principios de calidad como:

  • Claridad: nombres descriptivos para funciones y variables.
  • Reusabilidad: código modular y reutilizable.
  • Mantenibilidad: uso de comentarios y documentación en docstrings.
  • Confiabilidad: manejo de listas vacías y validación de datos.
