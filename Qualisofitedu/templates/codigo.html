Código y Buenas Prácticas

Buenas prácticas recomendadas:

  • Comentarios claros y funciones pequeñas.
  • Convenciones de nombres y formato consistente.
  • Pruebas unitarias y manejo de excepciones.

Ejemplo PL/SQL (documentado)

FUNCTION calcular_promedio(p1 NUMBER, p2 NUMBER) RETURN NUMBER IS
BEGIN
  RETURN (p1 + p2) / 2;
END;
